# tabby-sidebar-scp 0.1.1

This release packages the current SFTP-style SCP sidebar interface in a standalone
Tabby plugin. Release tags and package versions use plain numeric semantic versions
(**`0.1.1`**, never `v0.1.1`).

## Changes since 0.1.0

- Redesigned the default **Remote** file browser toolbar to follow the layout
  and icon order of Better Sidebar's SFTP view: **favorite folders**, edit path,
  refresh, filter, create remote folder, upload file, and upload folder.
- Added persistent **remote folder favorites**, scoped by SSH host, username,
  and port, without reading or modifying Better Sidebar's own SFTP favorites.
- Added remote directory creation through a noninteractive SSH `mkdir`
  command, using validated absolute remote paths.
- Added file and folder upload buttons using Tabby's available native Electron
  pickers, with the existing Local browser view as fallback where unavailable.
- Refined the remote-first listing, breadcrumbs, Name/Size/Date/Permissions
  columns, and contextual file actions to better match the SFTP panel.
- Kept standalone SCP sidebar support. With Better Sidebar installed, SCP
  appears alongside **Profiles / SFTP** without modifying the upstream plugin.
- Cleaned up project documentation to show the current UI rather than old
  screenshots of discarded layouts.

## Tests

The Ubuntu VM GitHub Actions workflow tests the `main` revision before release:
unit tests, real loopback upload/download over legacy SCP, and Tabby 1.0.238
renderer smoke tests both standalone and with Better Sidebar 1.0.11.
The GUI checks assert the SCP toolbar controls and panel switching.

These smoke tests do **not** demonstrate the full upload-picker workflow,
favorite persistence within a running Tabby UI, manual drag-and-drop,
or Windows/macOS compatibility. Test with disposable files before production use.

## Install from this GitHub release

Download **`tabby-sidebar-scp-0.1.1.tgz`** from the release assets and
verify it with **`SHA256SUMS.txt`**. Close Tabby, install the archive to
Tabby's plugin directory, and restart Tabby completely. See
[installation instructions](https://github.com/p4535992/tabby-sidebar-scp#download-and-install-release-011).

This is a GitHub release; **it does not automatically publish to npm**.

## Requirements and limitations

- Tabby plugin runtime, local OpenSSH `ssh` and `scp` clients and working
  noninteractive authentication with trusted host keys.
- Remote browsing uses SSH with GNU `find`; transfers use legacy `scp -O`.
- Better Sidebar integration is an optional **DOM compatibility adapter**,
  not a supported upstream API. Changes to Better Sidebar may require updates.
- Downloading complex legacy SCP filenames may require explicit `scp -T`
  consent, which disables OpenSSH's remote filename verification.
- SCP can overwrite existing files. Confirm paths and test with unimportant data.
