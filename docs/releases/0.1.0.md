# tabby-sidebar-scp 0.1.0

First public GitHub release of the standalone **SCP file browser for Tabby**.

## Features

- SCP sidebar that works **with or without Better Sidebar**.
- Optional **SCP** tab beside **Profiles / SFTP** when Better Sidebar's compatible header is detected; standalone sidebar otherwise.
- SFTP-inspired, **remote-first** interface with remote/local/split modes, folder navigation, filtering, sorting, and file metadata.
- Upload and download over OpenSSH **legacy SCP** (`scp -O`); local and remote moves/renames, directory transfers, and drag-and-drop controls.
- Explicit confirmation before transfers, and opt-in for complex-name downloads where OpenSSH `scp -T` is required.

## Tested

GitHub Actions Ubuntu VM smoke tests cover unit tests, a real loopback SSH/SCP server, and actual Tabby 1.0.238 UI startup in both standalone and Better Sidebar 1.0.11 modes. These checks do **not** replace manual validation of drag-and-drop and compatibility on other operating systems.

## Installation

Download **`tabby-sidebar-scp-0.1.0.tgz`** from the assets below. Install it locally in Tabby's plugin directory, or build from source. A published npm registry package is **not** implied by this GitHub release. See [README](https://github.com/p4535992/tabby-sidebar-scp#build-install-and-test) and [Development guide](https://github.com/p4535992/tabby-sidebar-scp/blob/main/docs/DEVELOPMENT.md).

The release contains a compiled plugin package and SHA-256 checksums.

## Requirements and known limitations

- Tabby-compatible plugin runtime; tested with Tabby 1.0.238.
- Local OpenSSH `ssh` and `scp` executables, trusted host key and noninteractive SSH authentication.
- Remote server supporting **legacy SCP**, and GNU `find` for remote listings.
- The Better Sidebar bridge uses **DOM selectors**, not an official extension API; compatibility can change across releases.
- SCP can overwrite existing destination files; review paths carefully. Complex remote names require a separate explicit `scp -T` opt-in, which disables OpenSSH's remote filename check.
- UI drag-and-drop, visual parity, and Windows/macOS behavior still need manual testing before production use.

No changes to Better Sidebar itself are required.
